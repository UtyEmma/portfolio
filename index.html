LaraNotice

Write the message once. Deliver it through Laravel’s notification channels.

composer require utyemma/laranotice
Send a notification
use Utyemma\LaraNotice\Notify;

(new Notify('Welcome aboard'))
    ->greeting('Hello')
    ->line('Your workspace is ready')
    ->send($user, ['mail', 'database']);

After package setup, $user is your notifiable Laravel user. Read the setup guide.
