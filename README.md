# Portfolio

Static React portfolio built with Vite. Existing routes are separate HTML entry points, so project pages and the 404 page work on static hosting without a server-side router.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory. Static assets live in `public/assets/` and are served from `/assets/`.
